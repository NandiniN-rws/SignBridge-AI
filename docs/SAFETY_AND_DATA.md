# Safety, privacy and dataset
This is an assistive communication prototype, not a certified interpreter, diagnostic system, triage tool, or emergency response replacement. Keyword alerts are only flags for staff attention. Confirm every prediction and AI draft. Never let the system diagnose or prescribe.

No external dataset is bundled. Acquire INCLUDE or other ISL data through its legitimate source and review the current licence and terms. Hospital-specific signs should be validated with Deaf ISL users and qualified interpreters. Do not assume English glosses map one-to-one to ISL signs. Use anonymized signer IDs and signer-separated test data.

Production use requires authentication/authorization, encrypted storage and transport, explicit consent, retention controls, audit logging, security testing, clinical validation and legal/regulatory review. Do not use real patient data in this local prototype.
